========================================
  AI文章改写工具 V2 - 元宝版
========================================

[首次使用]

1. 双击运行 "安装依赖.bat"
   - 检查并安装 Python、Node.js
   - 安装 opencli 依赖
   - 下载 Playwright 浏览器

2. 双击运行 "启动工具.bat"
   - 首次启动会自动生成 config.yaml
   - 用记事本打开 config.yaml 填入 API 密钥
   - 保存后重新运行 "启动工具.bat"

3. 登录腾讯元宝
   - 在浏览器中打开 https://yuanbao.tencent.com
   - 扫码登录

[日常使用]

1. 双击运行 "启动工具.bat"
2. 在界面中选择改写模式和 AI 引擎
3. 粘贴文章 URL，点击"开始处理"

[支持的 AI 引擎]

- 腾讯元宝（免费，需要登录）
- 智谱 GLM（需要 API Key）
- DeepSeek（需要 API Key）

[目录说明]

- config.yaml         : 配置文件（API 密钥等）
- config.example.yaml : 配置模板（供参考）
- output\             : 输出目录
- logs\               : 日志目录
- opencli\            : 元宝命令行工具

[遇到问题？]

1. 运行 "检查环境.bat" 检查环境是否正常
2. 查看 logs\ 目录中的日志文件
3. 确认 config.yaml 中的配置正确
